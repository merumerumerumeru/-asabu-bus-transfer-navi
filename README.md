# 麻生バス乗継ナビ

地下鉄さっぽろ駅から南北線で麻生駅へ移動し、北海道中央バスの
**麻15・麻16・麻17（石狩庁舎前行き）**へ乗り継ぐ個人用PWAです。
目的地は **花川北2条5丁目** です。

## 現在の状態

Version 0.1は画面と乗継計算を確認する初期実装です。

> **重要:** 現在のバス・地下鉄時刻は仮データです。公式時刻表との照合が終わるまで、実際の移動には使用しないでください。

## 実装済み

- 現在時刻のリアルタイム表示
- 平日・土曜・日祝の自動判定と手動切替
- 現在地（職場・地下鉄さっぽろ駅・その他）
- ホームまでの移動時間
- 地下鉄遅延（0・+1・+3・+5分）
- 次に乗る地下鉄と麻生駅到着見込み
- 麻15・麻16・麻17の統合表示
- 次のバス3件と乗換余裕判定
- 設定の端末内保存
- PWA・オフライン表示の基本設定
- GitHub Pages向けベースパス


```bash

```
